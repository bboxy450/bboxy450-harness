# bboxy450-harness

A GUI-first coding-agent harness that renders rich content natively: streaming markdown, tool cards, diffs, terminal output, plans, approvals and images. It is built on the [bboxy450-term](https://github.com/bboxy450/bboxy450-term) toolkit. Run it standalone as a window, headless (`-p --json`) or over ACP, or run it inside bboxy450-term as a submodule seat.

Status: design. Start at `.bboxy/specs/harness-zoomed-out.md`.
